# AI 编程工具 Token 计划横评
------

> 用同一份月度用量，算算 DeepSeek V4 Pro API 直调、opencode Go、Mimo Token Plan Max 这三种方案到底差多少钱。

## TLDR 省流

以个人本月预估用量 484.2M 为基准：

| 方案 | 月费 | 折算月成本 | 相对 DS API 倍率 | 额度覆盖 | 备注 |
|------|------|-----------|-----------------|---------|------|
| DeepSeek V4 Pro API | 按量 | ¥90.32 | 1.0x | — | 缓存 ¥0.025/M |
| opencode Go | $10 | $10 / ¥72 | 1.5x | ✅ $60 额度（6 倍杠杆） | ⚠️ DS 折扣未同步，同步后等效 token +33% |
| Mimo API 直调 | 按量 | ¥857.54 | ~9.5x | — | 缓存 ¥1.40/M |
| Mimo Token Plan Pro | ¥329 | ¥329 | ~3.6x | ❌ 额度仅 ~353M，不够 | 需升级 Max |
| Mimo Token Plan Max | ¥659 | ¥659 | ~7.3x | ✅ 用量占 60%，有余量 | 比 API 直调省 ¥198 |

**结论**
- DeepSeek API 直调 ¥90/月，缓存红利吃满，成本碾压
- opencode Go **$10 月费、$60 月额度、6 倍杠杆**，折合约 $15 （135元） 等效DeepSeek API 价值，折算月用量完全覆盖。唯一问题是 DeepSeek 25% 折扣没同步，同步后等效 token +33%
- Mimo Plan Pro（¥329）额度不够，被迫升 Max（¥659）成本翻倍，中间没过渡档
- Mimo Plan Max 7.3 倍，缓存价差 56 倍是根本原因

下面是详细计算过程。

## 用量基准

以下数据来自 **20 天**的实际使用（≈月度 66%），同时是 Mimo Token Plan Max 的 **40% 额度用量**。按比例换算完整月度用量（÷66% ≈ ×1.5）：

| 类别 | 20 天实际 | 折算月用量 | Mimo 额度占比 |
|------|----------|-----------|-------------|
| 缓存命中 | 307.887 M | 461.831 M | — |
| 未命中（输入） | 12.323 M | 18.485 M | — |
| 输出 | 2.590 M | 3.885 M | — |
| **合计** | **322.800 M** | **484.200 M** | **~60%** |

缓存命中率大概 95%，编程助手场景的常态——项目文件、system prompt 每轮对话都在重复。

> 折算月用量 484.2M 占 Mimo 套餐额度的 60%，说明这个套餐对当前用量来说偏大，还有 40% 余量。

## 三个方案分别是什么

**DeepSeek V4 Pro 直调 API**
最直接的方式，官方或兼容接口调用，按 token 计费，用多少算多少。

**opencode Go**
[opencode Go](https://opencode.ai/docs/zh-cn/go/) 是个订阅计划，月费 $10（首月 $5），核心玩法是**花 $10 买最多 $60 的 API 使用额度**，额度按节奏释放：

| 限制维度 | 额度 |
|---------|------|
| 每 5 小时 | $12 |
| 每周 | $30 |
| 每月 | $60 |

5 小时最多花 $12，一周最多 $30，连续高强度写代码偶尔会碰到 5 小时上限。模型挺全的：DeepSeek V4 Pro/Flash、MiMo V2.5 Pro、Kimi K2.5/K2.6、GLM-5、Qwen3.5/3.6 Plus 等等，十几个模型随便切。额度用完还能用免费模型续命。

**但要注意它的计费倍率**：opencode 对 DeepSeek 的计价大约是官方价的 **4 倍**（零售标价 6x，订阅折后约 4x）。$60 额度 ÷ 4x = 约 **$15 的 DeepSeek 官方 API 价值**，相对 $10 订阅费是 **1.5 倍**。当前唯一的问题是 DeepSeek 的 25% 永久折扣还没同步，同步后同样 $60 额度能多用 33% 的 token。[issue #28846](https://github.com/anomalyco/opencode/issues/28846) 里发现的计费差异就是未同步导致的。

**如果 opencode 后续同步了 DeepSeek 的 25% 永久折扣**，4x 倍率不变但基数变小，同样的 $60 额度能多用 **33% 的 token**。同步前 $10 ≈ $15 官方 API，同步后 $10 ≈ $20 官方 API，越等越值。

**Mimo Token Plan Max**
Mimo 平台的高级套餐，¥659/月，包含 MiMo v2.5 Pro 等模型的 token 额度。以下用量数据是该套餐 **40% 额度**的消耗量。

## 算钱（折算月用量）

以下均按折算月用量 484.2M 计算。

### DeepSeek V4 Pro API

| 类别 | 计算 | 花费 |
|------|------|------|
| 缓存命中 | 461.831M × ¥0.025 | ¥11.55 |
| 输入 | 18.485M × ¥3.00 | ¥55.46 |
| 输出 | 3.885M × ¥6.00 | ¥23.31 |
| **合计** | | **¥90.32（≈$12.54）** |

### opencode Go

opencode Go **$10 月费，$60 月额度，6 倍杠杆**。按 4x DeepSeek 官方价计费，$60 额度折合约 $15 的 DeepSeek API 价值。折算月用量 DeepSeek 官方价 $12.54，在 $15 范围内，**月费就是 $10，不会超**。

唯一问题是 DeepSeek 25% 折扣还没同步，用的是旧价基数。同步后同样 $60 额度因为单价降低，等效 token +33%（$15 → $20 官方 API 价值）。

### Mimo

Mimo 也支持缓存折扣，但单价高很多。折算月用量：

| 类别 | 计算 | 花费 |
|------|------|------|
| 缓存命中 | 461.831M × ¥1.40 | ¥646.56 |
| 输入 | 18.485M × ¥7.00 | ¥129.40 |
| 输出 | 3.885M × ¥21.00 | ¥81.59 |
| **API 直调合计** | | **¥857.54** |
| **Token Plan Pro（¥329）** | 额度 ~353M，**不够覆盖 484.2M** | **¥329 + 超额费** |
| **Token Plan Max（¥659）** | 额度 ~807M，用量占 60% | **¥659** |

Mimo 两个套餐的取舍：
- **Plan Pro ¥329**：额度仅 ~353M（Max 的 7/16），折算月用量 484.2M 会超，要么降用量要么被收超额费。但倍率低（3.6x），适合用量能控制在 350M 以内的用户
- **Plan Max ¥659**：额度 ~807M，当前用量只占 60%，余量充足。但单价算下来 7.3 倍，为"余量安心"多付了一倍
- 套餐阶梯断层明显：Pro 够用时 ¥329（3.6x），Pro 不够被迫升 Max 就是 ¥659（7.3x），**中间没有 ¥400~500 的过渡档**

但不管选哪个，和 DeepSeek V4 Pro 的 ¥90.32 比，Mimo 的成本都在 **3.6~9.5 倍**。差距主要来自缓存价——DeepSeek ¥0.025 vs Mimo ¥1.40，**56 倍**。

## 总结

- **按量弹性首选**：DeepSeek V4 Pro API 直调，¥90/月，缓存红利吃满
- **性价比订阅**：opencode Go，**$10 月费、$60 月额度、6 倍杠杆**，折算月用量完全覆盖，倍率仅 1.5x。唯一变数是 DeepSeek 25% 折扣同步进度
- **Mimo 套餐的尴尬**：Pro（¥329）额度不够用，被迫升 Max（¥659）成本直接翻倍，中间没有过渡档。60% 用量下 Max 比 API 直调省 ¥198，但和 DeepSeek 比仍是 7.3 倍
- **缓存是核心变量**：DeepSeek 缓存价 ¥0.025/M vs Mimo ¥1.40/M，差 56 倍，95% 缓存命中率下 DeepSeek 的成本优势碾压级
