主代码示例

首先声明mod deno; 表明从 src/deno.rs 中导入mod 定义

1
2
3
4
5
6
7

mod deno;
use deno::hello;
use deno::get_data;
fn main() {
    hello("panda");
    print!("data: {}",get_data());
}

模块示例

这里先声明 src/deno 目录下的两个子模块，通过pub use 从当前模块中导出定义的两个函数 deno.rs

1
2
3
4

mod data;
mod hello;
pub use self::hello::hello;
pub use self::data::get_data;

}

    println!("Hello ,{}",name);
