TLDR 省流

结论

  • Mimo API 和 Token Plan 同时降价，API 降到和 DeepSeek 同价，Token Plan 三档套餐（Standard ¥99 / Pro ¥329 / Max ¥659）
  • 月度用量 538M 换算约 100.34 亿积分，Standard 档 110 亿刚好覆盖（91%），成本从旧 Max ¥659 降到 ¥99，降了 85%
  • Token Plan ¥99 vs API ¥100.34 = 0.99x（99 折），本质上就是 API 的包月预付版
  • Pro/Max 满额单价更低（8.7 折/8 折），但当前用量下额度严重过剩，单价反而更高，适合重度用户
  • opencode Go 仍是最低价选项（¥72），但差距从原来的数量级缩小到了 ¥27

三个方案分别是什么

DeepSeek V4 Pro 直调 API 最直接的方式，官方或兼容接口调用，按 token 计费，用多少算多少。

opencode Go opencode Go 是个订阅计划，月费 $10（首月 $5），核心玩法是花 $10 买最多 $60 的 API 使用额度，额度按节奏释放：

限制维度额度
每 5 小时$12
每周$30
每月$60

5 小时最多花 $12，一周最多 $30，连续高强度写代码偶尔会碰到 5 小时上限。模型挺全的：DeepSeek V4 Pro/Flash、MiMo V2.5 Pro、Kimi K2.5/K2.6、GLM-5、Qwen3.5/3.6 Plus 等等，十几个模型随便切。额度用完还能用免费模型续命。

但要注意它的计费倍率：opencode 对 DeepSeek 的计价大约是官方价的 4 倍（零售标价 6x，订阅折后约 4x）。$60 额度 ÷ 4x = 约 $15 的 DeepSeek 官方 API 价值，相对 $10 订阅费是 1.5 倍。当前唯一的问题是 DeepSeek 的 25% 永久折扣还没同步，同步后同样 $60 额度能多用 300% 的 token。issue #28846 里发现的计费差异就是未同步导致的。

如果 opencode 后续同步了 DeepSeek 的 25% 永久折扣，4x 倍率不变但基数变小，同样的 $60 额度能多用 300% 的 token。同步前 $10 ≈ $15 官方 API，同步后 $10 ≈ $60 官方 API，越等越值。

Mimo Token Plan Standard（🆕） Mimo 平台的入门套餐，¥99/月，含 110 亿积分。新的积分制计费规则下，缓存命中只要 2.5 积分/MTok，编程场景 96% 缓存命中率下非常划算。之前这个用量需要 Max 档（¥659，820 亿积分），用量仅占 12%，严重浪费；现在 Standard 档（¥99，110 亿积分）用量占 91%，刚好匹配。

在当前 96% 缓存命中率下：

  • Token Plan（¥99）≈ API（¥100.34），倍率 0.99x，几乎持平
  • Token Plan 是固定月费，API 按量浮动。如果某月缓存命中率下降（比如换了新项目、大量新代码），API 成本会上涨，Token Plan 则锁死 ¥99

本质上 Token Plan 就是 API 的 99 折包月预付版——积分费率完全对齐 DeepSeek 定价（¥10/亿积分），100.34 亿积分值 ¥1003.40，Standard 档卖 ¥99（110 亿积分），按实际用量算刚好 99 折。真正的价值不在折扣，在于固定月费不怕用量波动。

总结

  • Mimo 降价是最大变化：API 和 DeepSeek 同价，Token Plan 三档套餐，当前用量选 Standard（¥99）比旧 Max（¥659）省 85%
  • Token Plan 就是 API 的 99 折包月预付版：积分费率完全对齐 DeepSeek 定价（¥10/亿积分），Standard 档 110 亿积分卖 ¥99，按实际用量 100.34 亿算刚好 99 折
  • 三档套餐看用量选：Standard（110 亿）适合 100 亿/月，Pro（380 亿）适合 200300 亿/月，Max（820 亿）适合 500 亿以上。额度过剩反而单价更高
  • 按量弹性首选：DeepSeek V4 Pro API 直调，¥100/月，缓存红利吃满
  • 性价比订阅：opencode Go，$10 月费、$60 月额度、6 倍杠杆，折算月用量完全覆盖，倍率仅 0.72x。唯一变数是 DeepSeek 25% 折扣同步进度
  • Token Plan 的优势在于锁定成本：固定 ¥99/月，不怕缓存命中率波动。如果某月命中率下降，API 按量会涨，Token Plan 不变
  • 缓存是核心变量：命中率 96% 时 Token Plan ≈ API（0.99x），命中率越低 Token Plan 越划算
