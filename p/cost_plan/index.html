用同一份月度用量，算算 DeepSeek V4 Pro API 直调、opencode Go、Mimo Token Plan Max 这三种方案到底差多少钱。

TLDR 省流

以个人本月预估用量 484.2M 为基准：

方案月费折算月成本相对 DS API 倍率额度覆盖备注
DeepSeek V4 Pro API按量¥90.321.0x—缓存 ¥0.025/M
opencode Go$10$10 / ¥720.8x✅ $60 额度（6 倍杠杆）⚠️ DS 折扣未同步，同步后等效 token +300%
Mimo API 直调按量¥857.54~9.5x—缓存 ¥1.40/M
Mimo Token Plan Pro¥329¥329~3.6x❌ 额度仅 ~353M，不够需升级 Max
Mimo Token Plan Max¥659¥659~7.3x✅ 用量占 60%，有余量比 API 直调省 ¥198

结论

  • DeepSeek API 直调 ¥90/月，缓存红利吃满，成本碾压
  • opencode Go $10 月费、$60 月额度、6 倍杠杆，折合约 $15 （135元） 等效DeepSeek API 价值，折算月用量完全覆盖。唯一问题是 DeepSeek 25% 折扣没同步，同步后等效 token +300%
  • Mimo Plan Pro（¥329）额度不够，被迫升 Max（¥659）成本翻倍，中间没过渡档
  • Mimo Plan Max 7.3 倍，缓存价差 56 倍是根本原因

下面是详细计算过程。

三个方案分别是什么

DeepSeek V4 Pro 直调 API 最直接的方式，官方或兼容接口调用，按 token 计费，用多少算多少。

opencode Go opencode Go 是个订阅计划，月费 $10（首月 $5），核心玩法是花 $10 买最多 $60 的 API 使用额度，额度按节奏释放：

限制维度额度
每 5 小时$12
每周$30
每月$60

5 小时最多花 $12，一周最多 $30，连续高强度写代码偶尔会碰到 5 小时上限。模型挺全的：DeepSeek V4 Pro/Flash、MiMo V2.5 Pro、Kimi K2.5/K2.6、GLM-5、Qwen3.5/3.6 Plus 等等，十几个模型随便切。额度用完还能用免费模型续命。

但要注意它的计费倍率：opencode 对 DeepSeek 的计价大约是官方价的 4 倍（零售标价 6x，订阅折后约 4x）。$60 额度 ÷ 4x = 约 $15 的 DeepSeek 官方 API 价值，相对 $10 订阅费是 1.5 倍。当前唯一的问题是 DeepSeek 的 25% 永久折扣还没同步，同步后同样 $60 额度能多用 300% 的 token。issue #28846 里发现的计费差异就是未同步导致的。

如果 opencode 后续同步了 DeepSeek 的 25% 永久折扣，4x 倍率不变但基数变小，同样的 $60 额度能多用 300% 的 token。同步前 $10 ≈ $15 官方 API，同步后 $10 ≈ $60 官方 API，越等越值。

Mimo Token Plan Max Mimo 平台的高级套餐，¥659/月，包含 MiMo v2.5 Pro 等模型的 token 额度。以下用量数据是该套餐 40% 额度的消耗量。

opencode Go

opencode Go **10刀 月费，60刀 月额度，6 倍杠杆 **。按 4x DeepSeek 官方价计费，$60 额度折合约 $15 的 DeepSeek API 价值。折算月用量 DeepSeek 官方价 $12.54，在 $15 范围内，月费就是 $10，不会超。

唯一问题是 DeepSeek 25% 折扣还没同步，用的是旧价基数。同步后同样 $60 额度，等效 token +300%（$15 → $60 官方 API 价值）。

Mimo

Mimo 也支持缓存折扣，但单价高很多。折算月用量：

类别计算花费

Token Plan Max（¥659）额度 ~807M，用量占 60%¥659

Mimo 两个套餐的取舍：

  • Plan Pro ¥329：额度仅 ~353M（Max 的 7/16），折算月用量 484.2M 会超，要么降用量要么被收超额费。但倍率低（3.6x），适合用量能控制在 350M 以内的用户
  • Plan Max ¥659：额度 ~807M，当前用量只占 60%，余量充足。但单价算下来 7.3 倍，为"余量安心"多付了一倍
  • 套餐阶梯断层明显：Pro 够用时 ¥329（3.6x），Pro 不够被迫升 Max 就是 ¥659（7.3x），中间没有 ¥400~500 的过渡档

但不管选哪个，和 DeepSeek V4 Pro 的 ¥90.32 比，Mimo 的成本都在 3.6~9.5 倍。差距主要来自缓存价——DeepSeek ¥0.025 vs Mimo ¥1.40，56 倍。

总结

  • 按量弹性首选：DeepSeek V4 Pro API 直调，¥90/月，缓存红利吃满
  • 性价比订阅：opencode Go，$10 月费、$60 月额度、6 倍杠杆，折算月用量完全覆盖，倍率仅 1.5x。唯一变数是 DeepSeek 25% 折扣同步进度
  • Mimo 套餐的尴尬：Pro（¥329）额度不够用，被迫升 Max（¥659）成本直接翻倍，中间没有过渡档。60% 用量下 Max 比 API 直调省 ¥198，但和 DeepSeek 比仍是 7.3 倍
  • 缓存是核心变量：DeepSeek 缓存价 ¥0.025/M vs Mimo ¥1.40/M，差 56 倍，95% 缓存命中率下 DeepSeek 的成本优势碾压级
